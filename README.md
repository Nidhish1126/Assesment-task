 Task Manager - Full Stack Web Application
A modern Task Management System built with the MERN stack. This project features a robust Role-Based Access Control (RBAC) system with dedicated dashboards for Admins and Users.

 Technology Stack
Frontend: React.js, Tailwind CSS, and Framer Motion for animations.

Backend: Node.js and Express.js.

Database: MongoDB with Mongoose.

Deployment: Hosted on Railway.

 Role-Based Dashboards
The application provides different experiences based on the user's role:

👤 User Dashboard
Task Management: Users can create, view, and update their own tasks.

Personal Profile: Manage personal account settings.

Activity Tracking: Simple and clean interface to track daily progress.

🔑 Admin Dashboard
User Management: Full control to view and manage all registered users.

System Overview: High-level statistics of all tasks across the platform.

Advanced Controls: Special access to manage global settings and site data.

✨ Key Features
Secure Authentication: Login and Sign-up system using JWT.

Advanced Security: Uses httpOnly and SameSite: None cookies to protect user sessions.

Responsive UI: Beautiful finance-themed design that works perfectly on mobile and desktop.

Real-time Logic: Backend configured with CORS for secure and fast communication.
